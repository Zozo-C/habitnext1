## 9. 跨故事的數據關聯（Data Dependencies）

### Task（任務）數據如何流動

```
4.1 創建
  ↓
Task {
  userId, title, cue, identity, type,
  date, dailyTarget, history: {}
}
  ↓
┌─────────────────────────────────────────┐
│ 5.2 標記完成                            │
│ 更新 history[date] = {                 │
│   completed/value/subtaskCompletions   │
│ }                                       │
└─────────────────────────────────────────┘
  ↓
┌──────────────────────────────────────────────────────┐
│ 多個故事讀取 history 進行計算                       │
├──────────────────────────────────────────────────────┤
│ 6.1: 完成率 = sum(completed) / total                │
│ 8.1: 成就進度 = sum(value) / requirement            │
│ 8.2: 城市數據 = group_by(category).sum(completed)   │
│ 8.4: Focus Map = user input (Impact/Ability)       │
└──────────────────────────────────────────────────────┘
```

### Aspiration（嚮往）數據如何流動

```
8.3 定義/選擇
  ↓
Aspiration {
  userId, title, description
}
  ↓
  ├─→ 推薦習慣（聯繫 Habit）
  │   ↓
  │    3.1 顯示推薦列表
  │   ↓
  │    4.1 加入習慣 + 建立 AspirationHabit
  │   ↓
  │    8.3 Aspiration - Habit 關聯存儲
  │
  └─→ 焦點地圖（8.4 可選路線）
      ↓
       Impact/Ability 評估
      ↓
      Fogg 建議
      ↓
       4.1 批量加入
```
